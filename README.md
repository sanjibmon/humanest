# HumaNest Landing + Auth UI v5

This version removes cropped pillar/trust artwork from the layout. Pillar captions are real HTML text, pillar icons use the clean badge artwork, and the four trust icons are crisp inline SVGs. The customer login, Platform Login/MFA, trial signup and HRMS surfaces have responsive styles for desktop and mobile.

## Run
npm install
npm run dev

## Environment
Copy `.env.example` to `.env.local` and set the Supabase URL and publishable/anon key.
